# GBA Vault

Agregador web de ROMs de Game Boy Advance com visual moderno e integração com o emulador **GBA.js**.

## Como usar

1. Abra o `index.html` no navegador.
2. Clique em **Carregar ROM (.gba)** e selecione um arquivo.
3. Use **Abrir** em qualquer item da biblioteca para iniciar no GBA.js.

## Observações

- As ROMs ficam salvas no `localStorage` do navegador atual.
- O jogo abre em uma nova aba apontando para `https://gba.js.org/` com a ROM em Data URL.
- Use apenas ROMs que você possui legalmente.
